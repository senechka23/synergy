Здесь собраны задания по технологической (проектно-технологической) практике.
Каждый кейс вынесен в отдельную папку, чтобы их было проще запускать и проверять отдельно.

## 📁 Структура

- `case_01_birthdate` — работа с датой рождения на Python;
- `case_02_counter` — простой счётчик на HTML, CSS и JavaScript;
- `case_03_django_greeting` — небольшое Django-приложение с сохранением имени в БД;
- `case_04_calculator` — интерактивный калькулятор;
- `case_05_analysis` — аналитический обзор третьего кейса.

Внутри каждой папки есть свой `README.md` с короткой инструкцией по запуску.

## 🛠 Что использовалось

`Python 3` · `HTML5` · `CSS3` · `JavaScript` · `Django` · `SQLite`

## ▶️ Как проверять

Кейсы 2 и 4 запускаются обычным открытием `index.html` в браузере.
Для первого кейса нужен Python, а для третьего — Python и Django.
Подробные команды указаны внутри соответствующих папок.
