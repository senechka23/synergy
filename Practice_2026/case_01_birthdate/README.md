# Кейс-задача №1. Дата рождения

Программа запрашивает у пользователя день, месяц и год рождения, после чего:

1. определяет день недели;
2. определяет, был ли год високосным;
3. вычисляет возраст пользователя;
4. выводит дату рождения в формате `дд мм гггг`, где цифры изображены звёздочками.

В программе также есть проверка введённой даты: нельзя указать несуществующую дату или дату из будущего.

## Запуск

```bash
python main.py
```

Пример начала работы программы:

```text
Программа работы с датой рождения
------------------------------------
Введите день рождения: 15
Введите месяц рождения: 6
Введите год рождения: 2000
```

После ввода программа покажет день недели, информацию о високосном годе, возраст и дату в виде электронного табло.

Для работы достаточно стандартной библиотеки Python.
