# Кейс-задача №4. Интерактивный калькулятор

Калькулятор выполняет четыре математические операции над двумя числами:

- сумма;
- разность;
- произведение;
- деление.

Если пользователь вводит данные, которые нельзя преобразовать в числа, в поле результата отображается сообщение об ошибке.

## Запуск

Откройте файл `index.html` в браузере.
