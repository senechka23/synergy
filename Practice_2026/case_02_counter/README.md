# Кейс-задача №2. Счётчик

Простой счётчик на HTML, CSS и JavaScript.

## Возможности

- увеличение значения на 1;
- уменьшение значения на 1;
- изменение цвета окна результата:
  - положительное значение — жёлтый;
  - отрицательное значение — зелёный;
  - ноль — красный;
- блокировка кнопки `+` при достижении 10;
- блокировка кнопки `−` при достижении -10;
- вывод сообщения при достижении крайнего значения.

## Запуск

Откройте файл `index.html` в браузере.
