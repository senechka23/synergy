# Кейс-задача №3. Django-приложение с приветствием

Приложение позволяет пользователю ввести имя, сохранить его в базе данных SQLite и показать персонализированное приветствие.

## Реализовано

- форма ввода имени;
- модель `Visitor` с одним полем `display_name`;
- сохранение имени в базе данных;
- персональное приветствие после отправки формы;
- проверка пустого поля;
- CSRF-защита формы средствами Django;
- CSS-оформление;
- простой тест отправки формы.

## Установка и запуск

1. Создать виртуальное окружение:

```bash
python -m venv venv
```

2. Активировать его.

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Применить миграции:

```bash
python manage.py migrate
```

5. Запустить сервер:

```bash
python manage.py runserver
```

После запуска открыть `http://127.0.0.1:8000/`.

## Тестирование

```bash
python manage.py test
```
